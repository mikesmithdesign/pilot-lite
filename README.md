# The Pilot's House Lite: free one-page template for B&Bs and guesthouses

A single-file HTML template with an airy, photography-led style, smooth
scrolling (Lenis) and scroll-triggered animation. No build step, no
frameworks: open `index.html` and edit.

**Live demo:** https://pilot-lite.vercel.app

## Quick start

1. Edit the text directly in `index.html`: business name, address, phone,
   email, room names and prices.
2. Replace the photos in `img/` with your own (keep the filenames, or update
   the `src` paths).
3. Update the `tel:` and `mailto:` links to your own number and address.
